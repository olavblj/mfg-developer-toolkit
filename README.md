# MFG developer toolkit

MIT-licensed MFG runtime libraries and trusted upload tooling. Third-party dependencies and character assets retain their own licenses and notices. Character archives include Universal, Pocket and Hero under their recorded CC0 terms; the Sprout 3D model is excluded.

This staging toolkit is being bootstrapped in immutable steps. The uploader and local vendor archives are published first so the reusable workflow can pin a real tooling commit. Templates follow with that workflow pinned to a real commit. No private MFG repository access is needed.

The upload workflow creates private staging previews. Public game publication remains an owner action; this repository does not publish to production.
